# ==============================================================
# GLOSARIUM BAHASA TARRI (VERSI STABIL / PRODUCTION READY)
# ==============================================================

# -----------------
# 1. STRUKTUR UTAMA
# -----------------
titikawal { ... }    : Pintu masuk (entry point) utama untuk eksekusi program.
fungsi (atau fn)     : Deklarasi sub-rutin/fungsi baru.
undang               : Memasukkan modul/library ekstensi ke dalam file.

# -----------------
# 2. PERCABANGAN & OOP KELAS
# -----------------
kelas                : Deklarasi Objek Class / OOP Dasar (Misal: kelas Mobil { ... }).
perluas              : Pewarisan/Inheritance Class terhadap class lain (Extends).
jika (atau jk)       : Kondisi IF murni.
ataujika (atau ajk)  : Kondisi ELIF.
lainnya (atau lny)   : Kondisi ELSE.

# -----------------
# 3. PERULANGAN & ERROR HANDLING (Try-Catch)
# -----------------
coba (atau cb)       : Mencoba blok kode beresiko (Try).
tangkap (atau tgkp)  : Menangkap error jika blok Coba gagal (Catch). Contoh: tangkap(_e) {}
akhirnya (atau akhir): Eksekusi absolut blok setelah Try-Catch berakhir (Finally).

selama (atau slm)    : Perulangan berbasis kondisi nyata (While Loop).
ulangidari ... hingga: Perulangan iterasi dengan rentang (Singkatan: ulangd).
setiap ... dari      : Mengiterasi elemen (Singkatan: stp ... dr).
untuk ... dalam ...  : Perulangan pembedah List/Array (Singkatan: utk ... dlm ...).
hentikan (atau henti): Menerobos paksa keluar dari Loop (Break).
lanjutkan (atau lnjt): Melewati siklus Loop saat ini untuk melanjutkannya (Continue).

# -----------------
# 4. KONTROL NILAI & BOOLEAN
# -----------------
tampilkan (atau kemb): Mengembalikan nilai dari fungsi (Return).
sembunyikan          : Menghentikan return awal (Void Return).
Benar / Salah        : Tipe data Logis Mutlak (True / False).
Kosong               : Merepresentasikan kehampaan memori (None/Null).
dan / atau / bukan   : Operator konjungsi logika.
??                   : Null Coalescing Operator.
=, +=, -=            : Operator Mutasi assignment variabel & memori index.

# ==============================================================
# 5. FUNGSI BAWAAN / BUILT-IN LIBRARY (Fungsi Bawaan Asli/Standard Library)
# ==============================================================

# --- TEKS, TERMINAL, & I/O MURNI ---
cetak()               : Mencetak teks biasa ke terminal layar. (Persingkatan: ctk)
cetak_detail()        : Mencetak dengan pengecekan representasi Tipe Data khusus secara detil di layar.
masukkan()            : Menghentikan program untuk meminta input interaktif (Prompt Input dari Keyboard User).
panjang()             : Mengukur jumlah isi karakter/Array.
awal_kapital()        : Mengkapitalkan awalan huruf string.
ganti()               : Melompati teks (String Replace).
ubah_kata()           : Merekayasa huruf perkata murni.
slug()                : Mengubah spasi dan karakter aneh menjadi string siput lurus ramah-URL (Misal: "ke-sini").
tipe_data()           : Mengecek identitas tipe objek dalam memori (apakah list, kamus, INT, float?).

# --- UTILITAS & DATA MOCKUP (PEMBUATAN SAMPEL DATA) ---
angka_acak()          : Menghasilkan bilangan acak dinamis.
huruf_acak()          : Menghasilkan urutan huruf rahasia secara acak murni.
huruf_acak_rapi()     : Sama, dengan proteksi kapital dan estetika bacaan yang logis.
lorem_ipsum()         : Mengeluarkan teks sampel dummy 'Lorem Ipsum' untuk pengembangan User Interface.
kata_bijak()          : Fitur rahasia pemanggil untaian pepatah bijak secara acak!! 🌟

# --- STRUKTUR DATA (ARRAY & DICTIONARY) ---
unik()                : Menghilangkan redundansi elemen dari Array/List.
balik()               : Menukar urutan Array ke baliknya (Reverse).
tukar()               : Menukar dua posisi memori.
urutkan_data()        : Modul sorting built-in native (sangat cepat mengurutkan memori).
cari_data() / cari_index() : Mencari item/index pada array berdasarkan query.
kunci()               : Return keys dari Kamus (Dictionary JSON).
nilai()               : Return values dari Kamus/Dictionay.

# --- DEBUGGING LISENSI ---
lacak()               : Menelisik histori eksekusi panggilan memori (Stack Tracing khusus debug programmer).
batalkan()            : Menggugurkan program paksa ketika logic rusak dari luar.
lempar_pesan()        : Melempar "Exception" custom seperti "Raise Error" ke konsol dengan format estetik TARRi.

# --- JARINGAN ASING & JSON ---
ambil_data_api()      : Fetcher HTTP/API Request (seperti "requests" di Python). 
parse_json_api()      : Merakit String menjadi tipe "Kamus". 

# --- MANAJEMEN PENYIMPANAN FILE (FILE I/O OS) ---
kelolaTxt()           : Mengatur / Menyimpan / Membaca / Menimpa dokumen Teks Fisik secara native.
kelolaJson()          : Mengatur / Menyimpan modifikasi langsung File Format JSON sistem memori Desktop.
termasuk()            : Pengecek validitas keberadaan objek absolut (apakah ada/Tidak).

# ==============================================================
# 6. IN-BUILT WEB FRAMEWORK BUNDLE (Server Lokal & Rantai API)
# ==============================================================
(Modul mumpuni ketika menjalankan TARRI ditahap: tarri jalankan -w fileanda.tarri)

halaman()             : Merender routing penuh HTML secara otomatis ala Fast-API.
rute()                : Pendefinisian URL Path. Endpoint utama pada web builder.
tujuan()              : Fungsi penemu rute dari browser.
alihkan()             : Pengalihan URL paksa (URL Redirection) ke alamat rute lain saat pengguna login.
kembalikan_html()     : Respons server mentah tipe "Text/HTML Content-Type".
cetak_html()          : Cetakan string untuk blok HTML di backend web (Persingkatan: ctkh).
cetak_web()           : Mencetak data biasa ke Front-End Browser Response (Persingkatan: ctkw).

# ==============================================================
# 7. SQLITE DATABASE MURNI LOKAL
# ==============================================================
sqlite(nama_db)       : Menjalankan engine dan membuat/koneksi file `.sqlite` seketika.
-> simpan()           : Inject Data Insert.
-> ubah()             : Modifikasi Data di SQLite (Update).
-> hapus()            : Delete Data aman dari table.
-> ambil()            : Ambil sebatas satu baris.
-> ambil_banyak()     : Fetch Arrays Semua Record.
-> dimana(), atauDimana() : Operasi Logis Query Canggih Anti-SQL-Injection.
