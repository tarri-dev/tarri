# TARRI Language Extention

Dukungan penuh untuk bahasa pemrograman (scripting) TARRI pada Visual Studio Code.

## Fitur-Fiturnya:
- **Syntax Highlighting**: Mengenali kontrol logika, operator, tipe data, dan daftar lengkap fungsi built-in dari TARRI (Termasuk Database sqlite, mysql, JSON Parser, API, dan String interpolasi otomatis).
- **Auto-Complete (Snippets)**: Anda dapat menekan "Tab" pada kata tertentu (seperti `titikawal` atau `jika`) dan kerangka kerjanya akan otomatis dibuat utuh.
- **Auto Closing Pairs**: Pengetikan kurung secara otomatis `{ }` `[ ]` `( )` disesuaikan untuk struktur asli TARRI.
